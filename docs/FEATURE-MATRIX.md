# Функции Happ и реализация Phantom

Изучены все 14 оригинальных изображений. Номер соответствует `photo_N` без
копирования самих фотографий в поставку. Документация Happ проверена отдельно;
наличие общего Xray не считается доказательством совместимости клиента.

| Обнаружено / требуется | Референс | Реализация Phantom / предел |
|---|---|---|
| Подключение, выбранный сервер | 8, 10, 12, 14 | VpnService, настоящий TUN/HEV/Xray; старт TUN отделён от HTTPS-доступности |
| Статус в фоне / Live Activity | 11 | Foreground-уведомление с отключением; плитка Android |
| URL, буфер, QR, ручной ввод, JSON | 8 | URL, буфер, встроенный QR scanner, SAF файл, URI и JSON-редактор, экспорт JSON |
| Несколько подписок, раскрытие | 4, 8, 12, 14 | Несколько записей, раскрытие и сохранение состояния |
| Обновить, пинг, редактировать, закрепить, удалить | 10 | Рабочие действия меню; удаление с подтверждением |
| Название, описание, трафик, дата | 8, 12, 14 | HTTP/body-метаданные, `meta.serverDescription` составных JSON |
| Поиск, избранное | сценарий выбора | Панель серверов с поиском, звёздочками, сохранением выбора |

| Тайм-аут загрузки и уведомления | 5 | Настраиваемый HTTP timeout, отдельный канал уведомлений |
| Обновить/пинг/подключить при открытии | 5 | Реальные последовательные задачи, разрешение VPN через Android |
| User-Agent | 4 | Общий и отдельный для подписки; явная кнопка формата Happ JSON |
| HWID | 4, 5 + docs | UUID установки Phantom; не совпадает с закрытым HWID Happ. Провайдер может требовать перевыпуск |
| Дубликаты | 4 | Одинаковый URL обновляется; идентичные записи объединяются |
| Порядок/пинг/алфавит | 4 | Все три режима; отрицательные/отсутствующие результаты идут в конец |

| HTTP GET / HEAD | 2, 3 | Через отдельный реальный core в `:probe`; VPN не требуется отключать |
| TCP / ICMP | 2, 3 | Прямые тесты при выключенном VPN; ICMP зависит от разрешений ОС. Для составного узла отклоняются как неоднозначные |
| Double | 2 | Два запроса одной сессии ядра с Connection: close; лучший результат |
| Keepalive | 2, 3 | Один HTTP-клиент/connection pool, чтение ответа для повторного использования; точное устройство внутренних транспортов Happ не заявлено |
| URL, тайм-аут проверки | 2, 3 | Настраиваемые; явные ошибки вместо выдуманного пинга |
| Автовыбор/балансировщики | 14 + docs | Исходные Xray routing, leastLoad и burstObservatory сохраняются. Нет отдельного фиктивного «авторежима» |
| Proxy / Direct / Block | 7 | Профили domain/IP; импорт открытых совместимых правил Phantom/Xray/Happ, отбрасывание несовместимых полей запрещено |
| Приложения в VPN/напрямую | Android equivalent | Builder allowlist/denylist; список приложений и ручные package names |
| DNS, IPv4/IPv6, LAN | 11, 13 + docs | DNS URI; собственный DNS JSON сохранён; IPv6 туннелируется или блокируется; geoip:private → Direct по выбору |
| SOCKS5/HTTP, порты, авторизация | 6 | Настраиваемые входы; отдельный внутренний SOCKS для HEV |
| Доступ к прокси из LAN | 9 | Bind 0.0.0.0 только с логином и паролем; loopback по умолчанию |
| Mux | 11, 13 | Реальный Xray Mux для одиночного RAW/TCP без Vision; несовместимые случаи отклоняются |
| Фрагментация | 11, 13 | TLS ClientHello через Freedom dialerProxy; только совместимый одиночный TCP/TLS, JSON провайдера не модифицируется |
| On Demand | 13 | Системная постоянная VPN и блокировка без VPN; автоматический reconnect. Правила iOS по SSID/доменам не копируются |
| Xray TUN | 9, 13 | Использован HEV TUN backend; переключателя с иным смыслом нет |
| Размер текста, кнопки, оформление | 11 | Реальные размеры, три фиолетовых оттенка, чёрный фон, русский язык |
| Подвижная кнопка, scroll indicator | 11 | Не перенесены: фиксированная кнопка в прокручиваемой собственной компоновке |
| Матричный дождь | собственное требование | Canvas, белые символы и затухающие следы, lifecycle/screen/route gating, отключение анимаций |
| Скорость, сессия, общий трафик | 9 | HEV IP-счётчики; скорость по реальному времени; контрольные сохранения |
| Уровень логирования | 1 | Уровень **Phantom**, реально фильтрует безопасные события. Сырые логи ядра отключены |
| История DNS / Access.log | 1 | Не реализованы; не выдаются за историю запросов. Нельзя достоверно вывести DNS из одних access-записей при DoH/ECH |
| Push / Tunnel / Access / подписки | 1 | Единый безопасный журнал клиента. Нет отдельной службы push и копий журналов iOS |
| Сброс, FAQ, URL-схемы, о приложении | 9 | Подтверждение сброса, встроенная справка, phantom://import и протокольные ссылки, лицензии |
| Dev Settings | 9 | Непоказанные вложенные поля не выдумываются; доступен редактор полного Xray JSON |
| Provider ID / закрытое управление | docs | Не реализованы коммерческие команды Happ, принудительные ограничения UI и закрытые crypto links |
| AES-GCM/ограниченные подписки | docs | Понятный отказ, запрос исходного URL/JSON у провайдера; ключи не угадываются |

**Граница полноты:** это самостоятельный функциональный клиент, а не побитовая копия Happ.
Закрытые сервисы Happ, DNS history, произвольные правила On Demand iOS и точное
тождество Keepalive не заявляются. Проверки на vivo Android 17 перечислены отдельно
в отчёте проверки; успешная сборка не означает, что они выполнены.
