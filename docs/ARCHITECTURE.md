# Архитектура Phantom

Phantom — Kotlin/Compose-клиент с Xray-core. Основной процесс содержит UI,
VpnService и Go runtime libXray. До трёх процессов `:probe`, `:probe2` и `:probe3`
проверяют серверы независимо от активного туннеля. Устройства с малым объёмом памяти
используют один процесс проверки.

```text
Android-приложения
  → VpnService TUN (IPv4, IPv6 по настройке)
  → вход Xray-core 26.11.9 типа tun (TCP и UDP)
  → маршрутизация, DNS и балансировщики Xray
  → Proxy / Direct / Block
```

Phantom передаёт открытый Android-дескриптор через `xray.tun.fd` в JSON, созданном
для текущего запуска. Xray дублирует дескриптор. При отключении Xray освобождает
свою копию, затем Phantom закрывает Android-дескриптор.

## Защита от петель и DNS

`registerDialerController` и `registerListenerController` вызывают `VpnService.protect()`
для сокетов Xray. При обычном режиме и списке исключений Phantom исключает собственный
пакет из TUN. Защищённый DNS для начального разрешения имён узлов по умолчанию обращается
к `1.1.1.1:53`.

VPN объявляет DNS `1.1.1.1` и `8.8.8.8`. Для URI TUN передаёт порт 53 в DNS
outbound Xray с настраиваемым DNS/DoH. Полный JSON сохраняет собственный DNS и правила
провайдера. Android Private DNS и встроенный DoH приложений могут менять путь DNS.

IPv6 выключен по умолчанию. При отсутствии IPv6-адресов в Builder Android блокирует
эту семью для приложений VPN; `allowFamily(AF_INET6)` не вызывается. Включение добавляет
IPv6-адрес и маршрут `::/0`. Предпочтение семей DNS для URI настраивается отдельно.
Явные исключения приложений направляются Android напрямую по выбору пользователя.

## Состояние и жизненный цикл

`OFF → STARTING → TUNNEL → ONLINE`. ONLINE появляется после HTTPS-ответа через
локальный SOCKS текущего ядра. Проверка учитывает HTTP-статусы 100–599 как достижимость
HTTPS-узла. Неудачная проверка публикует существующий статус Phantom и может запустить
автоматический переход на другой профиль.

Сервис VPN объявлен с типом `systemExempted`. Команды запуска, остановки и смены
сети сериализуются. Сервис ожидает возврата физической сети и создаёт новый TUN
при восстановлении маршрута. В случае завершения процесса Android получает
`START_NOT_STICKY`. Плитка и уведомление используют команды существующего сервиса.

Проверки HTTP выполняются в процессах проверки. Для их исходящих сокетов fd передаётся
через Binder основному VpnService, который вызывает protect() и возвращает результат.
Так проверка другого сервера не подменяет текущий туннель. Пакеты Binder содержат одну
конфигурацию и настройки теста; URL подписки и каталог хранилища не передаются.
Стандартный замер использует повторный запрос по прогретому HTTPS-соединению.
Версия замера сохраняется вместе с результатом. При загрузке каталога и добавлении
или обновлении подписки Phantom проверяет профили без актуального замера.

## Хранилище и задачи

Каталог — AES-256-GCM с ключом Android Keystore, AtomicFile, Mutex и StateFlow.
Данные находятся в noBackupFilesDir; cloud backup и перенос данных исключены.
URL подписок не включаются в экспорт JSON. Экспорт содержит ключи серверов и
выполняется только по действию пользователя через Android Storage Access Framework.

HTTP, разбор конфигураций, Keystore, дисковые операции, проверки и JNI работают
на Dispatchers.IO. UI получает неизменяемые снимки через StateFlow. Обновление
подписки атомарно сохраняет прежний рабочий список при неудаче. Для поддерживаемых
URL OverSecure запрос выполняется через HTTPS `/fetch` с временной парой X25519.
Ответ расшифровывается ChaCha20-Poly1305 и разбирается обычным импортом Xray JSON.
Счётчики Xray опрашиваются каждые две секунды через отдельный маршрут за аутентификацией
SOCKS. Суммы сохраняются примерно каждые десять секунд и при штатном отключении.

Сырые сообщения Xray и HEV не сохраняются: они могут содержать секреты. Журнал Phantom
содержит классифицированные события в памяти, максимум 300 строк; выбранный уровень
действительно фильтрует записи. История DNS не имитируется.

## Анимация

Canvas рисует белые символы с 11 уровнями затухания; массивы столбцов и Paint создаются
через remember. Часы читаются в draw-фазе. Частота ограничена примерно 24–30 кадрами/с.
Canvas присутствует только на главном экране при работающем TUN, RESUMED lifecycle,
включённом экране и разрешённых анимациях. Уход со страницы или выключение экрана
удаляет coroutine кадров. Режим ONLINE не подменяет факт запуска TUN.
